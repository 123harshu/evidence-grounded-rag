Retrieval-Augmented Generation (RAG) is a framework that enhances Large Language Models (LLMs) by retrieving relevant information from external knowledge bases before generating a response. Standard transformer architectures rely solely on parametric memory learned during pre-training. RAG integrates non-parametric memory by indexing document chunks using dense vector embeddings generated by models such as sentence-transformers. 

During retrieval, hybrid search algorithms combine dense semantic embeddings with sparse BM25 keyword matching using Reciprocal Rank Fusion (RRF). RRF scores retrieved passages by taking the sum of inverse ranks across sparse and dense search results using the constant k=60.

Transformer models utilize multi-head self-attention mechanisms to calculate dynamic contextual relationships between sequence tokens.
